# Rule-Based AI Chatbot 🤖

This project is a simple Rule-Based AI Chatbot created using Python as part of the DecodeLabs AI Internship.

## Features
- Handles greetings
- Uses if-else logic
- Runs in a continuous loop
- Gives predefined responses
- Handles unknown inputs
- Exit command support

## Technologies Used
- Python 3

## How to Run
bash
python chatbot.py

# AI Classification Model 🌸

This project uses Machine Learning to classify Iris flowers using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Iris dataset classification
- Train-test split
- KNN model training
- Accuracy calculation
- Confusion matrix generation
- Flower prediction system

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Matplotlib

## Run the Project
bash
python classification_model.py
